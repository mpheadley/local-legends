# The Review Economy — Triptych (one thesis, three voices)
*Drafted 2026-07-28 · Opus · Status: DRAFT (outlet-first, needs [MATT:] beats)*

**Thesis:** The online review collapsed — not because people got dishonest, but because honesty stopped being expensive. When a real testimonial and a machine-forged one cost the same (nothing), the real one loses its only edge. The answer is not a better algorithm; it's disclosed, embodied, named honesty. Covers physical products, digital products, and services alike — same argument, one wall that no longer exists.
