# Bridges — Connective Tissue Drafts

Six passages that hold the manuscript together when the chapters are assembled. One file per bridge so each stays tight and revisable.

**Source for briefs:** `MANUSCRIPT-OUTLINE.md` at the repo root.

**Workflow:**
1. Open one bridge file on mobile.
2. Read the brief.
3. Write Matt's first draft into the `## Draft` section.
4. Save / commit.
5. Next session, Claude edits with questions — never rewrites.

**Rule:** Matt writes openings, endings, and vulnerable passages. Claude does not draft these — editorial only.

**Suggested order (from MANUSCRIPT-OUTLINE.md):**
1. B2 first — freshest material.
2. B1, B3, B5, B6 in any order.
3. B4 last — hardest.
