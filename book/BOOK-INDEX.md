## How to use this

- **Start every book session by loading `BOOK.md` + this file.** That is the minimum context for working on structure.
- **For work on a single chapter or profile:** load this index + the specific file. Do not pre-load adjacent chapters unless the task explicitly spans them.
- **For connective tissue work:** load this index + the memoir chapter + the profile it pairs with + the connective-tissue row in `BOOK.md`. Nothing else.
- **When a file's word count or status changes materially, update this index in the same session.** Otherwise stale entries will mislead the next session.

Load: this index. Grep for the topic. Open no files until you know which ones are worth opening.
